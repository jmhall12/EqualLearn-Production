LUMI 3D INTERACTIVE UPDATE

Install:
1. Back up your current assets/widgets/lumi.html.
2. Replace it with assets/widgets/lumi.html from this package.
3. Keep the filename lumi.html.
4. Test locally before pushing to production.

Changes:
- Animation commands now show a short reply, close the chat automatically, and perform the animation.
- The four learning activities are interactive 3D sorting games using the existing Three.js scene and renderer.
- Players select or drag 3D cards into 3D category portals.
- The activities cover stereotypes/facts, equality/equity, respectful responses, and digital safety.
- The previous multiple-choice answer buttons have been removed from gameplay.

Notes:
- Scores are temporary in the current session and are not saved to Firestore.
- Test mouse, touch, and mobile layout in the actual EqualLearn page before deployment.

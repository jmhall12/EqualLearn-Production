# EqualLearn Device Notifications — Final Setup

## Required server deployment
1. Deploy `workers/web-push/worker.js` to the existing `equallearn-web-push` Worker.
2. Keep the existing `PUSH_SUBSCRIPTIONS` KV binding and `VAPID_PRIVATE_KEY` secret.
3. Configure Cloudflare Worker secrets `FCM_CLIENT_EMAIL` and `FCM_PRIVATE_KEY` from a Firebase service account that can send FCM messages. Never commit these secrets.
4. Confirm `GET https://equallearn-web-push.jmhallig-a48.workers.dev/health` reports `webPushConfigured: true` and `fcmConfigured: true`.

## Android APK requirements
1. Firebase Android app package must be `com.equallearn.app`.
2. Set GitHub Actions secret `GOOGLE_SERVICES_JSON_BASE64` to the base64 content of that app's `google-services.json`.
3. Build a fresh APK using the updated workflow. It copies `resources/android/res/raw/equallearn_notification.wav` into Android `res/raw/` and creates the `equallearn_class_v2` notification channel.
4. Install the updated APK. In Android Settings > Apps > EqualLearn > Notifications, ensure **EqualLearn Class Notifications** is allowed and set to Alerting with sound.

## Student one-time setup
1. Student signs in once and taps **Enable Phone Notifications** (APK) or **Enable Device Notifications** (PWA).
2. Student grants Android/browser notification permission.
3. EqualLearn stores that device's push token/subscription for the signed-in UID and refreshes it automatically on subsequent visits.
4. Tap a received notification to open the linked EqualLearn lesson, assignment, quiz, discussion, or live session.

## Remember this device
The login form uses Firebase Auth local persistence when **Remember this device** is checked. It saves the authenticated session, not the password. Users must sign in again after explicit sign-out, clearing app/browser data, uninstalling the app, or a security/session revocation. Do not enable this on a shared/public device.

## Sound notes
- Android app: notification channel uses the bundled EqualLearn chime and vibration. Android's channel controls still apply.
- Web/PWA: browser/OS controls notification sound; the app cannot override silent mode, Do Not Disturb, site notification settings, or muted channels.
- Push requires a network connection and a granted permission. No code can silently grant notification permission.

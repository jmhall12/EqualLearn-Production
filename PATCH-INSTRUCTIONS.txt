EQUALLEARN — LUMI PERSISTENT ACROSS PAGES PATCH

WHY LUMI FLASHES
----------------
The current project embeds a separate iframe with id `equallearn-lumi-frame`
in individual HTML pages. A normal full-document navigation destroys the old
document and its iframe, then creates a new page and a new Lumi iframe. The
existing `ui-shell.js` only moves the current page's iframe to BODY; it does
not preserve that iframe across document navigations.

SOLUTION
--------
This patch introduces `app.html`, a persistent same-origin app host:

- `app.html` owns one long-lived Lumi iframe.
- The actual EqualLearn pages load inside `#equallearn-page-frame`.
- Internal page links navigate the child frame only.
- The parent app host and its Lumi iframe remain alive, so Lumi does not reload
  or flash when moving between Student, Teacher, and Admin pages.
- The content iframe delegates camera, microphone, display capture, autoplay
  and fullscreen so existing Live functionality can request device access.
- Per-page Lumi iframe copies are removed from 32 existing
  HTML pages to avoid duplicate widgets.

AUTOMATIC ENTRY BEHAVIOR
------------------------
- Direct visits to pages that load `ui-shell.js` are redirected into app.html
  with their original path/query/hash preserved.
- The login page remains the normal public login page.
- After a top-level login, `login.js` opens the persistent host at the correct
  role dashboard.
- When login is already inside the host, role redirect stays within the child
  frame.
- For the APK, `scripts/build-mobile.mjs` creates a mobile-only www/index.html
  that opens app.html?path=/login.html. The public website root index.html
  remains unchanged.
- Capacitor no longer uses the remote server.url, so the local app host opens
  immediately from bundled files. Firebase, Firestore, Worker APIs, and Live
  services still require internet.

INSTALL
-------
1. Extract this ZIP at the EqualLearn repository root.
2. Preserve the included folder structure and replace/add the listed files.
3. Commit and push to the same GitHub repository and main branch used for the APK.
4. Open GitHub Actions and run Build EqualLearn APK.
5. Verify both steps are green:
   - Verify persistent Lumi host and local login entry
   - Verify persistent host is included in Android assets
6. Download and install the new APK.
7. For browser testing, open a shell-managed page (for example
   /student/quizzes.html). It should redirect to /app.html?path=... and then
   internal page navigation should keep Lumi stable.

IMPORTANT
---------
- This changes the navigation container for pages using the EqualLearn shell.
  Test Student, Teacher, Admin and Live routes after installation.
- The content iframe includes `allow="camera; microphone; display-capture;
  autoplay; fullscreen; ..."` to delegate permissions. Android manifest/runtime
  camera and microphone permissions are still required for Live.
- Direct page routes are preserved in the app.html `path` query. The host
  updates that query as the child page navigates, so refreshing restores the
  current page route.
- Do not separately add a Lumi iframe to each page. app.html is now the single
  owner of the widget.
- This ZIP was validated for JavaScript syntax, config consistency, workflow
  guards and archive structure. It was not run in a live browser or an APK
  build during this session.
